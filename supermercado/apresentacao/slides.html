Sistema de Supermercado
e Filas de Caixa

Demonstração de um caso de uso completo

struct ponteiro fila pilha função recursiva matriz
Sistema de supermercado em C++ para a disciplina de Estruturas de Dados. O programa controla o cadastro de produtos, as filas dos caixas e o histórico de operações.
O sistema

O que o sistema faz

Controlar produtos, a fila de cada caixa e o histórico do que aconteceu.

O que ele faz

  • Cadastra produtos com código único, preço e estoque
  • Registra compras e distribui os clientes entre os caixas
  • Finaliza o atendimento e debita o estoque
  • Guarda o histórico e mostra as vendas por caixa

Escopo

  • Tudo em memória: ao encerrar o programa, nada é salvo
  • Limites fixos: 50 produtos, 5 caixas e 20 itens por compra
  • Um cliente por vez em cada caixa, na ordem de chegada
Todo o estado fica em memória: produtos, filas, histórico e a matriz de vendas. Os limites são fixos porque os vetores têm tamanho definido em tempo de compilação.
Como está montado

Tudo parte de uma struct Mercado

main.cpp
struct Mercado {
    Produto       produtos[MAX_PRODUTOS];   // cadastro
    FilaClientes  caixas[MAX_CAIXAS];       // 1 fila por caixa (ponteiros)
    PilhaOperacoes historico;               // histórico (ponteiros)
    int           vendas[MAX_PRODUTOS][MAX_CAIXAS];  // matriz
};

FilaClientes:  inicio -> [#1] -> [#2] -> [#3] -> NULL   (fim)
Pilha:         topo  -> [última operação] -> ... -> NULL

Cada parte do trabalho tem seu espaço próprio: vetor para o cadastro, ponteiros para fila e pilha, matriz para o relatório.

A struct Mercado reúne as quatro partes: o vetor de produtos, as filas dos caixas, a pilha de operações e a matriz de vendas. As setas mostram como os nós se ligam por ponteiro.
Os cinco conceitos

Onde cada um aparece no código

ConceitoFunçãoPara que serve
Ponteiroenfileirar, empilharnós ligados por proximo
Filaenfileirar / desenfileirarclientes de cada caixa, em ordem de chegada
Pilhaempilhar / listarHistoricohistórico, do mais recente para o mais antigo
RecursãobuscarProduto, somarCarrinhobuscar produto e somar a compra
totalVendidoProduto, liberarFilasomar linha da matriz e liberar memória
Matrizvendas[produto][caixa]quantidade vendida por produto em cada caixa

A recursão também aparece em somarCarrinho (total da compra) e na liberação da pilha ao sair do programa.

Cada conceito aparece em uma função concreta. A recursão é usada na busca do produto e nas somas: não é uma demonstração isolada.
Compilação

Compilar e rodar

terminal
$ g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o mercado
$ ./mercado
FlagO que faz
-std=c++17escolhe a versão da linguagem; o código usa to_string, do C++11
-Wallliga os avisos mais comuns do compilador
-Wextraliga avisos adicionais, além do -Wall
-pedanticreclama de qualquer coisa fora do padrão C++
-o mercadonome do arquivo executável gerado

Com essas flags o projeto compila sem nenhum aviso do compilador.

As três flags de aviso não mudam o programa: só fazem o compilador apontar código suspeito. Com elas o projeto compila limpo.
Caso de uso

Um dia no supermercado

Catálogo

101 Arroz 5kg · R$ 24,90 · 10 un
102 Feijão 1kg · R$ 8,50 · 20 un
103 Café 500g · R$ 18,00 · 3 un

Clientes

Ana — 2× arroz, 2× café
Bruno — 3× feijão
Carla — 2× café

Cenário

3 caixas ativos.
Chegada em sequência, caixa escolhido automaticamente.

O roteiro percorre o sistema inteiro: cadastro e erro de duplicidade → compras com auto-atribuição de caixa → filas → finalização com comprovante → bloqueio por estoque → histórico e relatório.

As telas a seguir vêm da execução do programa com este roteiro.

Carla continua na fila. A compra dela foi aceita no registro, mas o estoque é revalidado no atendimento. Sem isso, o sistema venderia café que não existe.

Esse é o ponto que mostra por que a regra "debita só ao finalizar" existe.
