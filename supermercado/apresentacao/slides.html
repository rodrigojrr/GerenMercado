e Filas de Caixa

Demonstração de um caso de uso completo

struct ponteiro fila pilha função recursiva matriz
Sistema de supermercado em C++ para a disciplina de Estruturas de Dados. O programa controla o cadastro de produtos, as filas dos caixas e o histórico de operações.
O sistema

O que o sistema faz

Controlar produtos, a fila de cada caixa e o histórico do que aconteceu.

O que ele faz

  • Cadastra produtos com código único, preço e estoque
  • Registra compras e distribui os clientes entre os caixas
  • Finaliza o atendimento e debita o estoque
  • Guarda o histórico e mostra as vendas por caixa

Escopo

  • Tudo em memória: ao encerrar o programa, nada é salvo
  • Limites fixos: 50 produtos, 5 caixas e 20 itens por compra
  • Um cliente por vez em cada caixa, na ordem de chegada
Todo o estado fica em memória: produtos, filas, histórico e a matriz de vendas. Os limites são fixos porque os vetores têm tamanho definido em tempo de compilação.

Código · 1 de 5

Uma struct guarda o sistema inteiro

main.cpp
struct Mercado {
    Produto       produtos[MAX_PRODUTOS];            // vetor de tamanho fixo
    FilaClientes  caixas[MAX_CAIXAS];                // uma fila por caixa (ponteiros)
    PilhaOperacoes historico;                        // pilha de operacoes (ponteiros)
    int           vendas[MAX_PRODUTOS][MAX_CAIXAS];  // matriz: produto x caixa
};

Cada parte do trabalho tem seu espaço próprio: vetor para o cadastro, ponteiros para fila e pilha, matriz para o relatório. Campos de controle (totalProdutos, numCaixas, faturamento) foram omitidos.

A struct Mercado reúne as quatro partes: o vetor de produtos, as filas dos caixas, a pilha de operações e a matriz de vendas.

Avance para destacar um campo por vez: é a mesma declaração do main.cpp, só com os comentários encurtados.
Código · 2 de 5 · ponteiro + fila

Fila: entra no fim, sai do início

main.cpp · enfileirar
void enfileirar(FilaClientes &fila, const Cliente &cliente) {
    NoCliente *novo = new NoCliente;
    novo->dado = cliente;
    novo->proximo = NULL;

    if (fila.fim == NULL) {  // fila vazia
        fila.inicio = novo;
        fila.fim = novo;
    } else {
        fila.fim->proximo = novo;
        fila.fim = novo;
    }
    fila.tamanho++;
}

O nó

struct NoCliente
Cliente dado
NoCliente *proximo

enfileirar

aloca o nó e encadeia no fim. Os dois ramos do if são alternativas: fila vazia ou fila com gente.

desenfileirar

tira o inicio, avança inicio = inicio->proximo e dá delete — por isso é FIFO.

O ponteiro aparece duas vezes: cada nó aponta para o próximo e a fila guarda dois ponteiros, inicio e fim.

Nos passos 3 e 4, mostre que só um dos ramos do if executa: com a fila vazia, inicio e fim recebem o nó novo; com fila cheia, o nó entra depois do fim.
Código · 3 de 5 · ponteiro + pilha

Pilha: o último a entrar é o primeiro a sair

main.cpp · empilhar
void empilhar(PilhaOperacoes &pilha, const string &descricao, double valor) {
    NoOperacao *novo = new NoOperacao;
    novo->descricao = descricao;
    novo->valor = valor;
    novo->horario = horarioAtual();
    novo->proximo = pilha.topo;

    pilha.topo = novo;
    pilha.tamanho++;
}

A ordem muda em uma linha: novo->proximo = pilha.topo (o novo nó aponta para o antigo topo) e depois pilha.topo = novo. É o inverso da fila, que preserva o inicio.

Leitura do histórico: como cada operação entra no topo, listarHistorico caminha de topo até NULL e mostra o mais recente primeiro.

Se a estrutura fosse uma fila, a ordem da listagem seria a inversa. O histórico do slide 15 é exatamente essa pilha sendo percorrida.
Código · 4 de 5 · recursão

A busca que chama a si mesma

main.cpp · buscarProduto
// Recursao: procura o produto do indice "i" ate o fim do vetor.
int buscarProduto(const Produto produtos[], int i, int total, int codigo) {
    if (i >= total) {          // caso base: acabaram os produtos
        return -1;
    }
    if (produtos[i].codigo == codigo) {   // achou
        return i;
    }
    return buscarProduto(produtos, i + 1, total, codigo);   // passo recursivo
}

Pilha de chamadas · procurando o código 103

buscarProduto(p, 0, 3, 103) // 101 != 103, desce
buscarProduto(p, 1, 3, 103) // 102 != 103, desce
buscarProduto(p, 2, 3, 103) // achou: retorna 2
retornos: 2 <- 2 <- 2 // a pilha desempilha na volta
O caso base é o if do índice: quando i chega ao total, a função para e devolve -1. Sem ele, a recursão nunca terminaria.

A mesma técnica aparece em somarCarrinho (total da compra), totalVendidoProduto e totalVendidoCaixa (somas da matriz) e na liberação da memória ao sair do programa.
Código · 5 de 5 · matriz

Matriz: produto × caixa

main.cpp · totalVendidoProduto
// Recursao: soma uma linha da matriz de vendas (um produto em todos os caixas).
int totalVendidoProduto(const int vendas[][MAX_CAIXAS], int linha, int coluna,
                        int numCaixas) {
    if (coluna >= numCaixas) {
        return 0;
    }
    return vendas[linha][coluna] +
           totalVendidoProduto(vendas, linha, coluna + 1, numCaixas);
}

Uma linha por produto

vendas[i][j] guarda a quantidade do produto i vendida no caixa j. Somar a linha dá o total do produto; somar a coluna, o total do caixa.

Duas recursões

totalVendidoProduto anda nas colunas; totalVendidoCaixa anda nas linhas. Ambas usam o mesmo caso base: o índice passou do fim.

A matriz é indexada por posição do produto no vetor, não pelo código. Por isso a finalização do atendimento faz buscarProduto antes de somar.

FlagO que faz
-std=c++17escolhe a versão da linguagem; o código usa to_string, do C++11
-Wallliga os avisos mais comuns do compilador
-Wextraliga avisos adicionais, além do -Wall
-pedanticreclama de qualquer coisa fora do padrão C++
-o mercadonome do arquivo executável gerado

Com essas flags o projeto compila sem nenhum aviso do compilador.

As três flags de aviso não mudam o programa: só fazem o compilador apontar código suspeito. Com elas o projeto compila limpo.
